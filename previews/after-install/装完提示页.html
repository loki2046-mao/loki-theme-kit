二、先跟你说清楚一件事（免得误会）

配色和整套 UI 是两层。

  • 第一层（已经装好了）：配色、文字、边框、圆角、投影、字体、成功/警告/危险状态色。

换一套 = 一眼就看出来变了。

  • 第二层（还没做）：侧栏、卡片、会话行、气泡、代码块、表格这些具体 UI 部件，

也跟着变成这套主题的样子（纸面纹理、贴纸圆边、撕口、计数器编号、扫描线、四角准星…）。

第二层没法通用地搬过去 —— 每个界面的结构不一样，得针对你的界面单独适配一遍。 想要就跟你的 Agent 说一句：

「连 UI 部件也一起变」

（如果你用的是改不了源码的桌面应用，也是同一句话；Agent 会自己在外面接上去。）

四、"我选的那套会不会丢？" —— 讲清楚，别到时候懵

你的界面是什么重启应用升级你要做什么
能改源码的项目（网页/自己的应用）在在（写进代码了）什么都不用做
改不了源码的桌面应用会掉会掉说一句「把外观恢复回来」，或者装一次「开机自动恢复」让它自己回来

为什么桌面应用会掉：它是个打包好的程序，只能从外面挂上去，程序一重启就没了 （你的原文件一个字节没动，所以也不会有残留）。 怎么让它不掉：装一次常驻守护（对你 Agent 说「我要开机自动恢复」）。 之后不管是重启、退出重开、还是应用升级，打开就是你的外观。

关于"沿用"的另一个提醒：如果那个应用本来就有自己的皮肤系统， 我们不会抢它 —— 你选它自带的皮肤时，我们自动让位；你选我们的套组时， 两套都还在，随时切回来。
