# 5 分钟上手（给第一次用的人）

这份文档不用你懂 CSS。按顺序做，遇到卡住的地方把屏幕上的字发我就行。

> **如果你有 AI 助手（Cursor / Claude Code / Cola 这类）**：直接把这句话发给它——
> *"用 loki-theme-kit 给我的项目接上外观主题"*。它会自己跑
> `python3 scripts/auto.py --project <你的项目>`，自动认出你的项目类型、把接入包放好、
> 把那一行 script 插进去，还会回读验证给你看。你什么都不用做。
> 下面这些是给"想自己动手"或者助手没跑通时看的。

## 先说一句话

这里有 **35 套现成的界面外观**（作者自己做了大半年、每天在用）。你可以挑几套装进自己的
App，也可以在它们基础上改成自己的。**装的时候不会动你现有任何文件**，只往一个新目录里
写文件，不想要了删掉那个目录就行。

## 第 0 步：先看看（不用装）

浏览器直接打开演示页：

```bash
open previews/demo/demo.html
```

那是一个示例界面，右下角可以切 35 套主题，随便点。**它不会改你电脑上任何东西。**

## 第 1 步：跑一条命令

```bash
python3 scripts/start.py
```

它会问你几个问题（要哪几套、放哪儿），你一路回车就行。不想回答问题就
`python3 scripts/start.py --yes`。

跑完你会得到一个文件，和**一行要贴的代码**。

## 第 2 步：贴那一行，完事

在你网页的 `<head>` 里加：

```html
<script src="./loki-themes/loki-themes.js"></script>
```

就这样。你的网页立刻有了外观主题，**右下角会出现一个「外观」按钮**，点开可以切主题，
你选的会被记住。不想要了就删掉那一行，一切回到原样。

先不想动自己的项目？直接打开这个看效果（那张页面本身一行样式都没有）：

```bash
open previews/dropin/index.html
```

## （可选）第 3 步：想让主题更精确

刚才那种叫「一行接入」：它管的是页面底色、文字、标题、链接、按钮、输入框这类通用元素。
如果你还想让**卡片、侧栏、说话气泡**这些具体元素也跟着变，有两条路：

**省事的做法**：在 script 标签上加一个参数，让它自动给常见元素贴标签：

```html
<script src="./loki-themes/loki-themes.js" data-autotag="on"></script>
```

**精细的做法**：换「深度接入」——跑向导时在第 1 步选 2，或者在向导里选完再手工给元素加
class。这条路要做三件事，逐条说人话在下一节。

## 深度接入的三件事，逐条说人话

**① 让页面认识主题**

在你 App 的全局样式文件里加一行：

```css
@import "./loki-themes/index.css";
```

*全局样式文件*一般是 `app/globals.css`、`src/index.css`、`style.css` 这种名字。找不到就把
你的项目目录发我，告诉我看。

**② 告诉页面现在用哪套**

打开你 App 的页面 HTML，找到最外层的 `<html>` 标签，加一个属性：

```html
<html data-theme="loki-ease">
```

`loki-ease` 就是套组的名字（想换哪套就换这个值）。做完这一步，界面应该已经变了——
如果没变，先看 `troubleshooting.md` 的第 1 条。

**③ 给元素贴标签（可选，但决定效果多少）**

主题靠"标签"认人：它知道 `.loki-surface-strong` 是主卡片、`.loki-nav-item` 是导航项。
你的卡片上挂了这个标签，主题就知道该装饰它。

挂法就是加一个 class：

```html
<div class="my-card loki-surface-strong">…</div>
```

**一个都不挂也能装**，不会报错，只是几乎看不出变化。挂几个就有几处效果，可以慢慢加。

## 名词对照（看到这些词不用慌）

| 文档里的说法 | 说人话 |
| --- | --- |
| 套组 / set | 一整套外观 = 一个 CSS 文件 + 一个说明文件 |
| 令牌 / token | 一组"颜色开关"。比如"页面底色""正文颜色""强调色" |
| 契约类名 / hook | 给元素贴的标签，主题靠它认人。`loki-surface`、`loki-nav-item` 这种 |
| 结构件 | 形状上的特征：圆角、边框、投影、编号……（决定"像什么"） |
| 宿主 / host | 你自己的那个 App |
| 装饰槽位 | 留给图片的位置，默认空着；想放自己的小图标就填它 |

## 给设计师：不写 CSS 也能做一套自己的

1. **拿一张你自己的图**（截图、海报、照片、某个喜欢的界面都行）。
2. 跑：

   ```bash
   python3 scripts/palette.py 你的图.png
   ```

   它会告诉你这张图里的主色各占多少面积，并给出"哪个色当底、哪个当正文、哪个当强调色"
   的建议，还会直接生成一段可以粘贴的代码。**如果它提示某个色对比度不够，一定要理它**——
   那意味着字会看不清。
3. 跑：

   ```bash
   python3 scripts/new-theme.py --id 你起的英文名 --label "中文名" --group art
   ```

4. 打开新生成的那个 `theme.css`，里面已经标好了该填哪几行。想让它"有性格"，从
   `design-language.md` 里挑两三个形状特征抄进去（那文件里每条都带现成代码）。
5. 跑 `python3 scripts/check.py --only 你起的英文名`。它会告诉你还缺什么——**缺结构件
   就是这个意思：你只换了颜色，还没换形状**。

设计师最容易漏的是第 4 步：颜色一改就觉得"我做了一套主题"，结果看起来还是原来那个界面。
真正的区别在形状上。

## 常见问题（白话版）

**装完没变化？** 先确认 `data-theme` 加在 `<html>` 上（不是 `<body>`），再确认那行
`@import` 的路径是对的。

**切主题时闪一下？** 把 `theme-switcher-flash-guard.html` 里的那段脚本放进 `<head>`
最前面。

**某些元素没变？** 说明那些元素还没贴标签（第 ③ 步），或者被你自己 App 的样式盖住了。

**能改主题的名字吗？** 能。装的时候用 `--prefix th-`，或者直接把 `data-theme="…"` 的值
改成你喜欢的；套组内容不依赖名字。

**能只装一套吗？** 能：`python3 scripts/install.py --only loki-ease --out ./my-themes --with-switcher`。

**会改坏我的项目吗？** 不会。安装只在目标目录里写**新**文件；目标目录里已有同名文件时
它会拒绝覆盖（除非你手动加 `--force`）。

**这些主题是免费的吗？可以用在商业项目吗？** 是，可以。
